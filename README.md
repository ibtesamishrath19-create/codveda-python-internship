# Simple Calculator

## Project Description
A simple Python calculator that performs basic arithmetic operations.

## Features
- Addition
- Subtraction
- Multiplication
- Division
- User can choose an operation
- Handles division by zero

## Technologies Used
- Python

## How to Run
1. Open the project in VS Code.
2. Open the terminal.
3. Run:

```bash
python calculator.py

```markdown
## Example
The calculator takes two numbers from the user and performs the selected arithmetic operation.
